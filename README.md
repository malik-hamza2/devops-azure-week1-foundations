# 🚀 Azure DevOps Week 1 Foundations (Simulated via GitHub)

This repository simulates **Azure DevOps** project management concepts using 
**GitHub Issues, Projects, and Wiki**, as part of my Week 1 DevOps Internship 
training at Contour Software House.

Since Azure DevOps access was not available, the same Agile structure 
(Epics → Features → Tasks, Boards, Sprints, and Wiki documentation) has been 
recreated using GitHub's native tools — demonstrating that these concepts are 
tool-agnostic and apply across platforms.

## 📌 Sample Project: CI/CD Pipeline for Web Application Deployment

A realistic DevOps scenario covering containerization and automated deployment 
workflows.
